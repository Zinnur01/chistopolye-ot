# Охрана труда · АО «Холдинговая компания «Чистополье»

Сайт-справочник, который открывается по QR-коду: видео-инструкции, правила безопасности, действия при ЧС, схемы эвакуации и телефоны.
Работает на любом телефоне без установки, при желании добавляется на главный экран как приложение и открывается без интернета.

Всё бесплатно: хостинг — GitHub Pages, видео — RuTube или VK Видео.

## Что где

| Адрес | Что это |
|---|---|
| `/` | Сам сайт |
| `/admin/` | Админка для ответственного (работает с телефона) |
| `/qr.html` | Печать QR-кодов: общий и для каждой инструкции |

Ссылки для QR на конкретные страницы:
- инструкция — `…/#/i/<id>`
- раздел — `…/#/cat/<id>`
- ситуация ЧС — `…/#/sos/<id>`
- схема — `…/#/scheme/<id>`

`id` создаётся один раз и не меняется при правках, поэтому распечатанные коды продолжают работать.

## Как Женя редактирует контент (с телефона)

1. Один раз получить ключ доступа: в админке нажать «Как получить ключ» и выполнить 5 шагов.
2. Открыть `https://<сайт>/admin/`, вставить ключ и войти.
3. Добавить или изменить инструкцию, нажать «Готово», затем **«Опубликовать»**.
4. Через 1–2 минуты изменения появятся на сайте.

### Видео
- **Лучше всего:** загрузить ролик на RuTube или VK Видео, нажать «Поделиться», скопировать ссылку и вставить в поле «Ссылка на видео».
- Короткий ролик (до 25 МБ) можно загрузить прямо на сайт кнопкой «Загрузить видеофайл».
- YouTube в России работает медленно, его лучше не использовать.

### Тест после видео
В поле «Проверочные вопросы» каждый вопрос пишется так:
```
Можно ли перевозить людей на навесном орудии?
- Да, на короткое расстояние
+ Нет, никогда
```
`+` — правильный ответ, `-` — неправильный, между вопросами пустая строка.

## Публикация (один раз)

1. Создать публичный репозиторий на GitHub и загрузить туда эти файлы.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Статистика посещений (Яндекс Метрика)

Подключено: счётчик № 114172447 (`zinnur01.github.io/chistopolye-ot`).

Отчёты видит только владелец счётчика (и те, кому он сам даст доступ).

1. Зайти на https://metrika.yandex.ru под своим Яндекс-аккаунтом → «Добавить счётчик».
2. Адрес сайта — `https://<логин>.github.io/<репозиторий>/`, включить «Вебвизор».
3. Скопировать номер счётчика (8–9 цифр) и вписать его в `index.html` вместо `0` в строке `var METRIKA_ID = 0;`.
4. Закоммитить и запушить. Данные начнут появляться через несколько минут.

Что видно в Метрике: число посетителей и визитов, новые и вернувшиеся, время на сайте, какие инструкции открывали, город, устройство и браузер, откуда пришли (например, по QR-коду), а во «Вебвизоре» — записи визитов.
Имён Метрика не показывает: посетители анонимны. На `localhost` счётчик не включается, чтобы не засорять статистику.

## Локальный просмотр

```bash
python -m http.server 8080
```
Затем открыть http://localhost:8080. Админку можно попробовать в демо-режиме: http://localhost:8080/admin/.

## Устройство

- Без сборки и зависимостей: HTML + CSS + JavaScript.
- Все тексты лежат в `data/content.json`; загруженные файлы — в `assets/uploads/`.
- Админка сохраняет изменения коммитами через GitHub API.
- `sw.js` кэширует сайт, чтобы он открывался без сети.
- После правок в `assets/app.css` или `assets/app.js` увеличьте `?v=` в `index.html`, иначе телефоны могут показывать старую версию.
